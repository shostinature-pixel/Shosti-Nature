# Shosti Nature - মেথি মিক্স (Methi Mix) ই-কমার্স ল্যান্ডিং পেজ ও অ্যাডমিন সিস্টেম

বাংলাদেশের বিশ্বস্ত প্রাকৃতিক ব্র্যান্ড **Shosti Nature**-এর মেথি মিক্স (Methi Mix) পণ্যের জন্য একটি সম্পূর্ণ, আধুনিক, প্রিমিয়াম ও রিয়েল ফুল-স্ট্যাক সিঙ্গেল-প্রোডাক্ট ল্যান্ডিং পেজ।

## ১. প্রধান বৈশিষ্ট্যসমূহ

- **ন্যাচারাল ও প্রিমিয়াম ডিজাইন:** গাঢ় সবুজ (#133926), পাতার সবুজ (#1F6E43), নরম ক্রিম (#FAF8F5) ও ক্লাসিক শুভ্র থিম। বাংলা টাইপোগ্রাফির জন্য অপ্টিমাইজড (Hind Siliguri)।
- **প্রাথমিক বিক্রয়মূল্য:** ৫০০ টাকা (৳ ৫০০)।
- **ডায়নামিক প্রাইসিং সিস্টেম:** অ্যাডমিন প্যানেল থেকে যেকোনো সময় পণ্যের মূল্য পরিবর্তন করা যাবে এবং তা তাৎক্ষণিকভাবে ডেটাবেসে ও ল্যান্ডিং পেজে কার্যকর হয়।
- **সার্ভার-সাইড নিরাপত্তা ও হিসাব:** পণ্যের মূল্য বা ডেলিভারি চার্জ কখনোই ক্লায়েন্ট-সাইড ইনপুটের ওপর নির্ভর করে না; সার্ভার ডেটাবেস রেট অনুযায়ী পুনরায় হিসাব করে।
- **বাংলাদেশের উপযোগী ক্যাশ অন ডেলিভারি (COD):** ১১ ডিজিটের সচল মোবাইল নম্বর যাচাই (01XXXXXXXXX) এবং ডাবল সাবমিশন প্রতিরোধ।
- **অর্ডার ট্র্যাকিং সিস্টেম:** ক্রেতারা তাদের মোবাইল নম্বর বা ইউনিক অর্ডার আইডি (যেমন: `SN-261010-8492`) দিয়ে লাইভ স্ট্যাটাস দেখতে পারেন।
- **সুরক্ষিত অ্যাডমিন প্যানেল:**
  - পাসওয়ার্ড সুরক্ষিত অ্যাডমিন সেশন
  - অর্ডারের পরিসংখ্যান (মোট অর্ডার, পেন্ডিং, প্রসেসিং, ডেলিভার্ড, মোট রাজস্ব)
  - সার্চ ও স্ট্যাটাস ফিল্টারিং
  - এক ক্লিকে অর্ডার স্ট্যাটাস পরিবর্তন
  - পণ্যের মূল্য (৳ ৫০০), স্টক স্ট্যাটাস ও ডেলিভারি চার্জ সম্পাদন
  - Excel/Sheets-এর জন্য UTF-8 CSV এক্সপোর্ট
- **বাস্তব ও দায়িত্বশীল ব্র্যান্ডিং:** কোনো মিথ্যা বা ভুয়া স্বাস্থ্য দাবি নেই; বিশুদ্ধ প্রাকৃতিক খাদ্য উপাদানের সততাপূর্ণ উপস্থাপনা ও স্পষ্ট হেলথ ডিসক্লেইমার।
- **SEO ও অপ্টিমাইজেশন:** OpenGraph কার্ড, Twitter মেটা ট্যাগ এবং Schema.org Product (JSON-LD) স্ট্রাকচার্ড ডেটা।

## ৩. লোকাল কম্পিউটারে রান করার নিয়ম

### পূর্বশর্ত
- Node.js (ভার্সন 18 বা তার বেশি)
- npm বা yarn অথবা bun

### ইনস্টলেশন ধাপসমূহ:
```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার করুন
cp .env.example .env

# ৩. ডেভেলপমেন্ট সার্ভার চালু করুন (পোর্ট 3000)
npm run dev
```
ব্রাউজারে চালু করুন: `http://localhost:3000`

## ৪. অ্যাডমিন প্যানেল প্রবেশ ও মূল্য পরিবর্তন

1. ব্রাউজারে `http://localhost:3000/#admin` এ যান অথবা পেজের হেডারের ডান পাশের **লক আইকন** / ফুটারের **প্রশাসক প্রবেশ (Admin)** বাটনে ক্লিক করুন।
2. ডিফল্ট পাসওয়ার্ড: `shosti2026`
   *(প্রোডাকশনে `.env` ফাইলে `ADMIN_PASSWORD="আপনার_গোপন_পাসওয়ার্ড"` সেট করে সহজেই পরিবর্তন করা যাবে)*
3. লগইন করার পর:
   - **মূল্য ও স্টোর সেটিংস** ট্যাবে যান।
   - বিক্রয় মূল্য (বর্তমানে 500) পরিবর্তন করে আপনার কাঙ্ক্ষিত মূল্য দিন।
   - "পরিবর্তন সংরক্ষণ করুন" বাটনে ক্লিক করুন।
   - এটি তাৎক্ষণিকভাবে ডেটাবেসে সংরক্ষিত হবে এবং ল্যান্ডিং পেজেও নতুন দাম দেখাবে।

- সিস্টেম স্বয়ংক্রিয়ভাবে আপনার আসল ছবিটি অগ্রাধিকার দিয়ে প্রদর্শন করবে।

## ৬. Supabase ডেটাবেস সংযোগ (ঐচ্ছিক / প্রোডাকশন ক্লাউড)

যদি আপনি ফাইল-ভিত্তিক স্টোরেজের পরিবর্তে ক্লাউড PostgreSQL / Supabase ব্যবহার করতে চান:
1. [Supabase](https://supabase.com)-এ একটি নতুন প্রজেক্ট তৈরি করুন।
2. Supabase SQL Editor-এ গিয়ে `supabase/schema.sql` ফাইলের কোড রান করুন।
3. `supabase/seed.sql` রান করে প্রাথমিক ডেটা লোড করুন।
4. `.env` ফাইলে আপনার `VITE_SUPABASE_URL` এবং `VITE_SUPABASE_ANON_KEY` যুক্ত করুন।
